# Deep White hero comparison

BRAND-001, [issue #1](https://github.com/chaseac-cpu/is117-brand-studio-cc/issues/1). AI-created explorations for the learner's agreed brief. Neither direction has been chosen.

- [A: Measured depth](../../public/explorations/modernist.html): grid, geometric rhythm, sans-serif hierarchy. Primary reference: Josef Müller-Brockmann, _Beethoven_, 1955, [designer's foundation](https://syjmb.foundation/en/josef-mueller-brockmann/). Downloaded reference image inspected: broken concentric arcs, asymmetric composition, compact aligned type. Translation aims at precision, with a risk of impersonality.
- [B: Surface tension](../../public/explorations/postmodernist.html): serif/sans-serif juxtaposition, offset frames, print texture. Primary reference: Wolfgang Weingart, _Schreibkunst (The Art of Writing)_, 1981, [LACMA](https://collections.lacma.org/object/207227). Downloaded reference image inspected: halftone layering, stepped edges, overlapping strips and varied lettering. Translation aims at individual style, with a risk of distraction.

The references inform composition rather than being reproduced in the previews. Both use the existing white-shirt SVG and identical headline, supporting copy, action and disclaimer. Performance features remain proposed and untested. Styles are isolated in the exploration directory.
